# CoChem-SCRIBE Master Execution Workflow (2026-08-07)

This document maps the complete, step-by-step execution workflow for the `CoChem-SCRIBE` module. This workflow transforms SCRIBE into a continuous, autonomous background daemon that secures massive datasets in real-time and effortlessly scaffolds rigorous, publication-ready academic manuscripts.

## Stage 1: Asynchronous Daemon Spawning
1. **BASE Instantiation:** During Stage 5 of `CoChem-BASE`, SCRIBE is initialized not as a sequential script, but as an `asyncio` background daemon (`scribe_doc_manager.py`).
2. **Tensor Attachment:** SCRIBE connects to `cochem_state.h5` as a read-only spectator.
3. **Memory-Aware Archiving Loop:** Throughout the execution of TOPOS, TORQ, and SpycFit, SCRIBE actively monitors RAM utilization. When the HDF5 tensor hits the 500MB threshold (due to massive DVR grids or $J=80$ rotational partition functions), SCRIBE compresses the delta payload using Zstandard (`.tar.zst`) and flushes it to the Solid State Drive, ensuring total provenance and preventing I/O kernel crashes.

## Stage 2: Dynamic Log Ingestion & Academic Compilation
1. **Execution Termination:** Once SpycFit completes the final Bayesian optimization, it signals SCRIBE to begin the active assembly phase.
2. **Dynamic Parsing:** `scribe_payload_builder.py` actively parses the raw ORCA `.out` and MACE `.log` execution streams rather than relying on static JSONs. It detects any adaptive fallbacks (e.g., MACE dropping to AIMNet2 due to transition metals) that occurred mid-pipeline.
3. **LaTeX & BibTeX Generation:** 
   - SCRIBE auto-generates an APS-compliant `Methodology.tex` block detailing the exact DFT functionals, Basis Sets, MLFF tiers, and grid parameters (e.g., `DefGrid4`).
   - **Conditional Assembly:** SCRIBE utilizes a Jinja2 templating engine. If a specific module (e.g., TORQ) was skipped during execution, SCRIBE gracefully drops its methodology section from the LaTeX payload to prevent compilation failures.
   - It queries the **CrossRef API** to pull exact DOI citations for the utilized theories, instantly generating the complete `manuscript.bib` file.
4. **LAM Protocol Justification:** SCRIBE checks the HDF5 metadata for the `LAM_TRIGGER_REQUIRED` flag. If TRUE, it automatically injects a rigorous justification paragraph into the LaTeX file detailing why the rigid-rotor harmonic approximation failed and Colbert-Miller Sinc-DVR was utilized.

## Stage 3: Publication Artifact Generation
SCRIBE unpacks the finalized `cochem_state.h5` tensor and routes the data through its visualization generators:
1. **TOPOS Artifacts:**
   - Renders interactive HTML 3D Carousels (`py3Dmol`) for the top isomer geometries.
   - Extracts NCI domains into `.cube` files.
   - Outputs LaTeX tables for chiral bucket distributions and Plotly stacked bar charts for Boltzmann thermodynamic populations.
2. **TORQ Artifacts:**
   - Plots 2D probability wavefunctions derived from the Sinc-DVR eigenvalues overlaid on classical Potential Energy Surfaces.
   - Generates anharmonic vs. harmonic infrared overlay graphs and TikZ diagrams for A/E tunneling splittings.
   - Plots UV-Vis Natural Transition Orbitals (NTOs) from STEOM-CCSD as `.cube` renders.
3. **SpycFit Artifacts:**
   - Renders Plotly scatter charts demonstrating the drift from the Rigid *ab initio* priors to the Bayesian-fitted posteriors.
   - Generates Box-and-Whisker plots displaying the statistical variance leverage derived from the Leave-One-Isotopologue-Out (LOIO) cross-validation routine.
   - Outputs final `.svg` vectors of the JAX Voigt spectral convolutions (Microwave and UV-Vis).
4. **Mass Spectrometry Artifacts:**
   - Parses the final mass fragmentation distributions from QCxMS and renders $m/z$ abundance bar charts via Plotly.

## Stage 4: Scaffolded LLM Inference
1. **Payload Assembly:** SCRIBE feeds the final, highly accurate SpycFit Bayesian parameters, rotational constants, and identified kinetic barriers into a heavily constrained prompt string.
2. **Gemini API Execution:** The LLM interprets the physical constants and drafts the initial "Results & Discussion" section for the manuscript.
3. **Offline Fallback Transparency:** If SCRIBE is executing on an air-gapped system, it defaults to the offline generation script and explicitly applies a bold watermark stating that the AI interpretation phase was bypassed.

## Stage 5: Legacy Bundling & Finalization
1. **Pickett Extraction:** SCRIBE isolates the `.lin`, `.cat`, and `.fit` files strictly generated by SpycFit.
2. **Verification Zipping:** These specific files are bundled into a `Legacy_Verification.zip` archive to allow classical spectroscopists to independently cross-validate the machine learning predictions using legacy SPFIT/SPCAT codes.
3. **Master Assembly:** SCRIBE zips all generated figures, `.tex` files, `.bib` files, and the `cochem_state.h5` database into the final `Run_YYYYMMDD.tar.zst` master archive.
4. **Pipeline Conclusion:** SCRIBE displays the final readout in the Jupyter UI. The CoChem Pipeline execution is fully concluded.
